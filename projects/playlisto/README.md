# Playlisto
**Turn Google Drive into your personal music streaming server**
## Description
Developed a personal cloud music server that streams Google Drive media seamlessly across web browsers and Kodi
## Tech Stack
- Python
- FastAPI
- React
- TypeScript
- Google Drive API
- HTTP Streaming
- Kodi Add-on
