# HPCCFS
**Build a production-like HPC cluster from scratch using open-source technologies**
## Description
Designed and documented a complete HPC cluster from the ground up, implementing centralized authentication, shared storage, workload scheduling, accounting, QoS, fairshare scheduling, software management with Environment Modules, and distributed MPI execution. The project serves as a comprehensive educational guide that closely follows real-world HPC center practices.
## Tech Stack
- Rocky Linux
- Slurm
- OpenMPI
- LDAP
- NFS
- Environment Modules
- Spack
- Munge
- MariaDB
- SlurmDBD
- Bash
- C
- MPI
